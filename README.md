# ML Visual Lab

**ブラウザで機械学習モデルを動かし、結果を目で確かめる日本語の実験サイトです。**

ChatGPTのWorkで作成しました。サンプルデータや自分のCSVを使い、回帰・分類・クラスタリングの設定を変えながら、予測線・決定境界・樹形図などを比較できます。

HTML・CSS・JavaScriptで構成された静的サイトで、データの前処理とモデルの学習はブラウザ内で実行します。バックエンド、APIキー、依存パッケージのインストール、ビルド処理は不要です。

## 試せること

| 学習の種類 | 対応モデル |
| --- | --- |
| 回帰 | 線形回帰、多項式回帰、ランダムフォレスト、サポートベクター回帰（SVR） |
| 分類 | ロジスティック回帰、k近傍法（k-NN）、ランダムフォレスト、サポートベクターマシン（SVM） |
| クラスタリング | k-means、階層的クラスタリング（Ward法・最短距離法・最長距離法・群平均法） |
| 強化学習 | Multi-Armed Bandit（Greedy・ε-Greedy・UCB）、Q-learning迷路、簡略状態のQ-learning Snake |
| 自然言語処理 | Bag of Words＋Logistic Regression（感情分析・5ジャンル分類） |

- 数値・カテゴリ列の指定、One-hotエンコーディング、標準化、Min-Maxスケーリング
- 学習・テストデータの分割と評価指標の比較
- 予測線、決定境界、混同行列、k-meansの反復過程、樹形図の可視化
- CSV／TSVの読み込みと、入力データ・変換後データ・予測結果のCSV保存
- 架空のサンプルデータによる、ばらつきやモデル設定の比較実験

## ローカルで起動する

Python 3と、ES Modules・Web Workerに対応したブラウザを用意してください。
リポジトリのルートで次を実行します。

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory dist
```

ブラウザで <http://localhost:8000> を開きます。終了するときはターミナルで `Ctrl+C` を押してください。

環境によっては `python` の代わりに `python3`、Windowsでは `py -3` を使います。ES ModulesとWeb Workerを使うため、`index.html` をダブルクリックするのではなく、HTTPサーバー経由で開いてください。

## 基本的な使い方

1. 「回帰」「分類」「教師なし」から学習の種類を選びます。
2. サンプルデータを選ぶか、CSV／TSVを読み込みます。
3. モデル、特徴量、目的変数、前処理を設定します。回帰は入力1列、分類・クラスタリングは入力2列を使います。クラスタリングでは目的変数を使いません。
4. 「モデルを学習する」を押し、図と評価指標を確認します。
5. 設定を変えて再学習し、必要に応じて結果をCSVで保存します。

### 入力データの条件

| 項目 | 条件 |
| --- | --- |
| ファイル形式 | CSV／TSV、UTF-8／Shift_JIS |
| ファイルサイズ | 最大2MB（2,097,152バイト） |
| 行・列 | 見出し行＋12〜5,000行のデータ、2列以上 |
| 見出し | 1行目に重複しない列名を指定し、空欄にしない |
| 数値 | 半角・桁区切りなし |
| カテゴリ入力 | One-hotを有効にする。1列につき最大32種類 |
| 分類 | 2〜8クラス、各クラス3行以上。ロジスティック回帰は2クラスのみ |
| SVM／SVR | 分割後の学習データが800行以内 |
| 階層的クラスタリング | 有効なデータが全体で500行以内 |

選択した入力列や目的変数に空欄・無効な値がある行は除外し、件数を画面に表示します。教師あり学習の前処理は学習データだけから計算し、テストデータにも同じ変換を適用します。

### データの扱いと用途

読み込んだCSVの内容はブラウザ内で処理し、アプリからサーバーへ送信しません。入力データや学習結果の永続保存機能はありません。残したいデータはCSV保存ボタンでダウンロードしてください。

同梱サンプルは学習用の人工データです。モデルは学習・実験向けのJavaScriptによる独自実装で、scikit-learnを実行するものではありません。モデルによっては最適化が収束せず、近似結果である旨が画面に表示されます。

## 購買パターン探索（Apriori / FP-Growth / Eclat）

上部の「購買パターン」タブで、同じ購買データを3手法で探索・比較できます。回帰・分類・教師なし・強化学習と同じページ内で切り替わります。依存パッケージやビルドは不要です。

- 手で追える10件、スーパー、まとめ買いの架空データを用意。生成データは100〜5,000件、Seedで再現できます。
- 最小支持度（1〜100%）と最大サイズ（1〜5商品）を変更し、頻出組合せ・支持度・処理時間を比較します。3手法の結果は商品集合と出現件数まで照合します。
- 組合せをクリックすると該当するレシートを強調。Aprioriの候補と枝刈り、FP-Growthの実際の初期FP-tree、Eclatの商品別取引IDも確認できます。
- 確信度で関連ルールを絞り込み、支持度・確信度・リフトを表示します。読みやすさのため結論は1商品に限定。ルールは因果関係や購入順序を表しません。
- 自分のデータは**見出し・取引IDなし、1行が1購買、カンマ区切りの商品名**で入力するか、UTF-8のCSVを読み込みます。最大2MB・5,000件・32商品、商品名80文字まで。空行・空欄を除去し、同一購買内の重複商品を1つとして数えます。
- 購買データ、全頻出組合せ、確信度で絞った全ルールをCSV保存できます。表は上位100件、グラフは上位10件、レシートは先頭12件の表示です。

```csv
パン,牛乳
パン,卵,バター
牛乳,卵
```

探索は専用Web Workerで実行し、中止や条件変更で停止できます。頻出組合せ20,000件、探索の計算量・時間に上限を設け、超過時は部分結果を完成した結果として表示せず、条件変更を案内します。処理時間は各手法1回の実測であり、厳密なベンチマークではありません。共通の入力整形・結果ソート・ルール生成・描画は測定に含めません。

実装は `dist/association/`、画面の入口は `dist/index.html` です。`/#association`（または `index.html#association`）で購買パターンタブを直接開けます。旧URLの `association.html` も自動転送します。タブの切り替えはブラウザの戻る・進むに対応し、購買タブを離れると実行中の探索を中止します。戻ったときはデータと設定、完了済みの結果を保持します。見出し・フッターは全実験で共通です。

`npm test` で全列挙との一致、ランダムデータ、支持度境界、CSV、ルール計算、Workerを検証します。任意の画面テストは既存のPlaywright環境で `node tests/association-browser.mjs` を実行します。5タブの切り替え、探索の停止と再実行、旧URLの転送、戻る・進む、スマホ表示も検証します。

## 自然言語処理（NLP）

上部の「自然言語処理」タブ、または `/#nlp` で開きます。「感情分析」「ジャンル分類」を選ぶと、同梱の5,000件版CSVで自動学習します。「自分の文章で試す」に文章を入力して「分析」を押すと、同じブロック内に予測ラベルとクラス別の予測確率を表示します。その下で、単語分割 → Bag of Wordsの出現回数ベクトル → Logistic Regressionの単語の寄与を確認できます。

| データ | 分類先 | 分割 |
| --- | --- | --- |
| `dist/nlp/csv/bow_sentiment_reviews_5000.csv` | 0＝低評価、1＝高評価 | 学習4,000 / 検証500 / テスト500件 |
| `dist/nlp/csv/bow_japanese_training_5000.csv` | IT・テクノロジー、食事・料理、旅行・観光、スポーツ、金融・経済 | 学習4,000 / 検証500 / テスト500件 |

語彙・重みの学習には `split=train` の文章とラベルだけを使います。検証・テストは学習後の評価専用で、語彙構築やパラメータ選択には使いません。`id`、`sentiment`、`domain` などのメタデータを特徴量には含めません。

- 単語分割にはブラウザ標準の `Intl.Segmenter('ja')` を使用します。NFKC正規化・英字の小文字化を行い、句読点と空白を除きます。助詞は残し、原形化・ストップワード除去は行いません。ブラウザの辞書の違いにより分割や予測が多少変わる場合があります。
- Bag of Wordsは単語の出現回数です。学習語彙にない単語は無視し、画面では破線で区別します。語彙数、全認識単語の回数、先頭24次元の対応表、全次元の数値配列を表示します。
- 分類は独自実装の多項ロジスティック回帰（softmax）。平均交差エントロピー＋L2正則化（0.001）を全件勾配降下法で180回更新します。学習率は学習入力の平均二乗ノルムに基づく固定値です。2クラスの場合も同じ実装を使います。
- 各クラスの確率、検証・テストの正解率、予測クラスへの単語の寄与（回数×重み、上位12語）を表示します。寄与はクラスのスコアに対する値で、確率の増減そのものではありません。
- 最大2,000文字。単語がすべて未知の場合は判定材料がない旨を表示し、切片だけによる確率を参考値として示します。「その他」クラスはありません。

モデルは語順・文脈を保持しないため、否定、皮肉、未知の言い回しに弱い教材用の分類器です。架空データ上の正解率は実際の文章への性能を保証しません。

実装は `dist/nlp/` に分離し、既存のCSVパーサー・DOMヘルパー・共通スタイルを利用しています。外部依存やビルドは不要です。CSV読み込み・学習・推論は専用Workerで実行します。タブを離れても学習を続け、入力・結果を保持します。テーマ変更・再学習時には前のWorkerを終了して、古い結果を破棄します。

NLPのロジックは `npm test`、画面は既存の検証用Playwrightを使う `node tests/nlp-browser.mjs` で確認できます。両テーマ、未知語、空入力、回数ベクトル、確率、切り替え、CSV失敗と再試行、390px幅の表示を検証します。

## Reinforcement Learning

上部の「強化学習」から **Multi-Armed Bandit → Q-learning迷路 → Snake** の順に体験できます。データやCSVの用意は不要です。

| 教材 | 操作 | 学べること |
| --- | --- | --- |
| Multi-Armed Bandit | Greedy・ε-Greedy・UCB、ε（ε-Greedyのみ）、3〜5台のスロット、試行数、真の確率のシャッフルを変更 | 探索と活用のトレードオフ。選択回数、推定価値Q(a)、累積・平均報酬を比較。UCBは各アームのUCB Scoreと探索Bonusも表示 |
| Q-learning / Maze | 3つの5×5迷路、α・γ・ε、Episode数、step上限を変更 | 即時報酬と将来価値の関係。全25状態のQ-tableと現在の方策、報酬・step数の推移を確認 |
| Snake | α・γ・ε、Episode数、step上限を変更 | 状態空間の増大と、状態を圧縮する利点・限界。盤面、Score、Reward、行動、生存step数の変化を確認 |

- **1ステップ**：Banditは1回の選択、迷路・Snakeは1回の行動とQ値更新を実行します。
- **自動実行 / Training**：指定した試行数・完了Episode数まで学習します。一時停止から再開できます。
- **Play / Evaluation**：迷路・Snakeの学習済みQ値を使用し、ε=0で約350msごとに行動します。Q-tableや学習グラフは更新しません。再生の一時停止・再開も可能です。
- **リセット**：Q値、学習履歴、環境、乱数列を初期化します。速度以外の設定変更でもリセットします。速度だけは進行中に変更できます。
- **迷路をランダムに再生成**：迷路プリセットの下のボタンで、壁・Trapを配置し直します。StartとGoalは左上・右下に固定し、Trapを避けてGoalへ到達できる配置を生成します。Random Seedを更新して「ランダム迷路」に切り替え、進行中の学習・再生を停止してQ-tableと履歴をリセットします。「リセット」やα・γ・εの変更では配置を保持し、同じSeedを指定すれば同じ迷路を再現できます。既存の3プリセットも引き続き選択できます。
- 迷路のマスをクリックすると4方向のQ値を表示し、最大の方向を強調します。全体の矢印も切り替えられます。同値の最大Q値は複数表示し、行動選択時はランダムに選びます。表示は現在の推定方策で、最適性を保証するものではありません。
- 迷路のロボットは論理座標（`env.position`）と描画を分離し、状態遷移を受け取った描画側（`robot-animator.js`）が「方向転換 → 歩行周期で1マス移動 → idle」を再生します。頭・胴・左右の腕・脚を個別に動かし、90度の方向転換では向きを変えてから歩き出します。学習のstep間隔・状態遷移・Q値更新・Reward計算・Episode終了条件には一切関与せず、到達マスの種類は描画側が `env.cells` から検知します。Play / Evaluationと1ステップで再生し、高速なTrainingでは瞬間移動で表示します。
- Goal到達は軽いジャンプ。Trap到達は感電演出（Trapマスの赤フラッシュ約150ms、ロボットの高速左右振動、周囲2〜3本の電撃、頭部ディスプレイの警告ノイズ、`Reward −10` のポップ表示、最後に小さな煙／全体約520ms）で、いずれも終了後はニュートラル姿勢へ戻り、通常のEpisode終了・リセット処理に影響しません。電撃・煙はCSS/SVGのみで描画し、画像素材やライブラリは追加していません。`prefers-reduced-motion: reduce` では歩行・振動・電撃の明滅・煙を省略し、赤フラッシュと `Reward −10` を短時間（約320ms）表示します。
- Banditの上部説明・下部の解説・数式は選択中のアルゴリズムに合わせて切り替わります。ε・探索率の入力欄はε-Greedyのときだけ表示し、Greedy・UCBでは隠します。UCBでは各アームに `探索Bonus = √(2·ln t ÷ N(a))` と `UCB Score = Q(a) + 探索Bonus` を表示し、次に選ばれる最大スコアのアームのカード上部に「UCB最大」バッジを付けます（未選択アームは ∞ で最優先）。バッジは絶対配置でカードの大きさ・位置は変えません。学習ロジック（`bandit.js` の `step()`）は変更していません。
- Banditの真の報酬確率は初期状態では非表示です。「真の確率を表示」で答え合わせできます。隣の「🎲 確率をシャッフル」は各アームの真の確率を新しいRandom Seedから作り直して表示し、Q値・選択回数・累積報酬・試行回数・グラフ・比較記録をすべてリセットします。真の確率は `armProbabilities(seed, arms)`（`bandit.js`、環境側で `step()` とは独立）で決まるため、同じSeedを入力すれば同じ確率を再現できます。
- 「現在の比較結果を記録」で直近6件を保持し、同じSeed・台数・試行数で手法やεを比較できます。比較記録は学習リセット後も残りますが、確率のシャッフルとページ再読み込みでは消えます。
- Random Seedは環境と行動選択で乱数列を分離しています。Banditは各アームのk回目の報酬抽選も手法間で共有し、速度や一時停止は結果に影響しません。
- εは設定値のまま一定で、自動減衰しません。α=0ではQ値を更新できません。学習不足や設定によっては、再生がGoalへ到達しない場合もあります。

### Snakeの方式と制約

**DQNは採用せず、簡略状態を使う表形式のQ-learningを実装しています。** 既存サイトの依存パッケージ・ビルド不要の静的構成を維持し、ニューラルネットワーク学習による追加依存や実行負荷を増やさず、3つの教材を動かすことを優先しました。Pythonバックエンドや外部APIは追加していません。

8×8盤面の状態を「4方向の危険（16通り）×Foodの相対方向（9通り）×進行方向（4通り）」の最大576状態へ圧縮します。移動は上下左右の4行動。Food取得で+10・長さ+1、壁や体への衝突で−10、通常移動で−0.1です。移動によって空く末尾への移動は可能です。迷路もGoal +10、Trap −10、通常移動・壁への試行 −0.1で、Goal・Trapを終端とします。

異なる体の配置が同じ簡略状態になるため、常に最適な行動を選べるわけではありません。step上限は時間制限による打ち切りで、学習時の将来価値を残します。真の終端（Goal・Trap・衝突・盤面クリア）では将来価値を0にします。

環境（`maze.js` / `snake.js`）、学習器（`qlearning.js`）、進行管理（`session.js`）、画面を分離しています。DQNを追加する場合は学習器を拡張し、経験再生・ターゲットネットワーク・非同期更新とWorkerとのモデル受け渡しを実装する構成です。UIにも「表のQ値をネットワークで近似する」という違いを説明しています。

### 実行負荷と学習グラフ

迷路・Snakeの学習は専用のES Module Workerで行い、約12ms以内の計算単位に分割して約80ms間隔で進捗を送ります。学習を1歩ずつアニメーションすることなく、停止操作を受け付けられます。別カテゴリや別の教材へ移動した場合、またはページが非表示になった場合は停止します。

学習は最大10,000 Episodes、1回の上限は2,000 stepsです。グラフは完了Episode（時間制限で打ち切った回も含む）を表示し、報酬・step数・SnakeのScoreに直近20回の移動平均を重ねます。長い履歴は描画点を間引きますが、学習履歴は保持します。評価再生は学習履歴に追加しません。

## 開発・確認

Node.jsとnpmがある場合は、`dist/` 配下の全JavaScriptの構文と、Node標準テストランナーによる自動テストを実行できます。`npm install` は不要です。

```sh
npm run check
npm test
```

Windows PowerShellで `npm.ps1` が実行ポリシーによりブロックされる場合は、`npm.cmd run check` を使ってください。

ソースの整形は必要なときだけ固定バージョンのPrettierで実行できます。サイトの実行にパッケージのインストールは不要です。HTML内の空白とJavaScript内の埋め込みテンプレートを保つ設定を使います。

```sh
npx --yes prettier@3.6.2 --write "dist/**/*.{js,html,css}" --single-quote --html-whitespace-sensitivity strict --embedded-language-formatting off
```

DOM取得・HTMLエスケープは `dist/shared/dom.js`、CSVファイルのダウンロードは `dist/shared/download.js` に集約しています。CSVの組み立ては各機能が担当します。共通スタイルは `dist/style.css`、各実験のスタイルは機能別のCSSに置き、購買パターンのスタイルは `.association-page` 内に限定しています。

テストでは既存の回帰・分類・クラスタリング全10モデル、One-hotと3種類のスケーリング、Banditの3手法、迷路のQ値更新・全プリセットのGoal到達・再現性、Snakeの餌・壁・体・末尾・盤面クリア・学習、Workerの停止・再開・リセットを確認します。

画面テストも実行する場合だけ、任意の検証用依存をGit管理対象外のキャッシュへ入れます。配信サイトの依存は増えません。

```sh
npm install --prefix .cache/qa --no-package-lock playwright
node tests/browser-smoke.mjs
```

画面テストはインストール済みのMicrosoft Edgeをheadlessで使い、一時HTTPサーバーを起動して終了時に閉じます。Chromeを使う場合は環境変数`QA_BROWSER=chrome`を指定してください。既存画面、3教材の操作、学習・再生、390px幅の横はみ出し、ブラウザ例外を検査します。スクリーンショットは`.cache/qa/screenshots/`に保存します。

CSV入出力などその他の操作は、ローカルサーバーでサイトを開いて確認してください。

ローカルの実験データは `data/local/` に置くとGitの管理対象から除外されます。配布用の `ml-visual-lab-source*.zip`、環境変数ファイル、依存パッケージ、ログ、エディターの個人設定も `.gitignore` で除外します。

## 静的サイトとして公開する

公開ディレクトリに `dist/` を指定するか、`dist/` 内のファイルを静的ホスティング先へ配置します。ビルドコマンドは不要です。`index.html` が公開先のトップに置かれ、JavaScriptが適切なMIMEタイプで配信されるように設定してください。

本アプリにはログイン機能がありません。閲覧範囲の制限が必要な場合はホスティング側で設定します。
